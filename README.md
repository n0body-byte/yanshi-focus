# 研时 · 考研专注钟

一款面向考研备考的本地专注工具，包含番茄计时、每日专注累计、历史趋势和 To Do 清单，不需要账号。

## Windows 桌面版

- `YanShi-1.2.0-Setup.exe`：推荐使用，会创建桌面快捷方式。
- `YanShi-1.2.0-Portable.exe`：无需安装，双击即可使用。

两个版本共用同一份本地数据，历史记录会自动保存到：

```text
%APPDATA%\YanShi\yanshi-data.json
```

关闭软件、重启电脑、移动便携版或升级软件都不会影响这份记录。卸载程序默认也会保留数据。

“偏好设置 → 数据安全中心”提供以下保护：

- 自动保留最近 7 份滚动备份，桌面版备份位于 `%APPDATA%\YanShi\backups`
- 一键导出或导入完整 JSON 数据
- 导入前自动备份当前任务和专注记录
- 手动创建即时快照，或直接打开桌面版数据目录
- 删除任务、清除已完成任务或删除专注记录后可在 6 秒内撤销

## 浏览器开发版

双击 `启动研时.bat`，浏览器会自动打开 `http://localhost:5173`。窗口内的命令行需要保持运行；关闭命令行窗口即可停止本地服务。

也可以在项目目录运行：

```powershell
node server.js
```

然后访问 <http://localhost:5173>。

## 使用提示

- 空格键：开始或暂停计时
- `R` 键：重置当前计时
- “完成本次”：提前结束并记录已专注的时长（至少 1 分钟）
- 任务支持置顶、搜索、改名，并显示累计投入时长；点击播放按钮可直接选中任务去专注
- 专注记录页提供 7/30 天日均投入、完整番茄率、高效时段与任务投入分布
- 专注明细可按任务名称搜索，并筛选完整番茄或提前完成记录
- 当前筛选出的专注明细可导出为 Excel 兼容的 CSV 文件
- 每次专注可记录具体目标或结果备注，并在历史中搜索和导出
- 计时运行时基于结束时间自动校准，减少高频磁盘写入并可靠跨越休眠或后台状态
- 桌面端数据保存异常与恢复会在界面中明确提示
- 桌面版可在专注时保持屏幕唤醒，并通过 Windows 任务栏显示当前计时进度
- 可配置长休息间隔，并选择是否自动开始休息和下一轮专注
- 可管理完成通知权限；桌面版在后台完成计时时会通过系统通知和任务栏提醒
- 支持每日与每周专注目标，并分别显示当前完成进度
- 偏好设置：可调整专注/休息时长、每日目标、提示音、自动休息并管理数据备份
- 在任务页按 `N` 快速新建任务，按 `/` 聚焦搜索框
- 浏览器出现“安装到桌面”按钮时，可将它安装为独立桌面应用

> 浏览器开发版的数据保存在浏览器本地；正式 `.exe` 桌面版使用独立 JSON 文件保存。
